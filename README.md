Dark Mode & Light Mode 🌙☀️


A simple and interactive Dark Mode & Light Mode project built with HTML, CSS, and JavaScript.


📌 About the Project


This project allows users to switch between Dark Mode and Light Mode by clicking a toggle button.


The interface changes its colors and appearance dynamically using JavaScript and CSS.

🌙 Dark Mode


☀️ Light Mode

🎨 Dynamic color changes

💻 How to Use




Open the project in your browser.


Click the theme toggle button.


The page switches between Dark Mode and Light Mode.


Click again to switch back.




🎨 Project Goal


The goal of this project is to understand how JavaScript can interact with CSS classes and change the appearance of a webpage dynamically.
